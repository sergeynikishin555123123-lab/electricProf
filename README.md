# 🔌 Электрик Finder - Telegram Mini App для Timeweb Apps

Сервис поиска электриков через Telegram Mini App. Полный аналог Profi.ru для электромонтажных работ.

## 📱 Демо-бот
@ElectricianFinderBot - поиск электриков в Зеленограде, Андреевке, Голубое
